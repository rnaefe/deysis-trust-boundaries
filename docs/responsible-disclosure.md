# Responsible disclosure

This project documents security research involving Dokuz Eylül University's DEYSİS attendance workflow. Operational integration details are intentionally withheld: no production endpoints, captured traffic, credentials, compatible request contracts, sensitive screenshots, or working production client are published.

The public implementation uses an intentionally incompatible mock protocol. Its purpose is defensive analysis, systems engineering, and architecture improvement. It is not affiliated with DEÜ and does not make claims beyond the evidence and limitations documented here.

For questions about this case study, open a GitHub issue in this repository. Do not include personal data, credentials, production traffic, or sensitive operational details.
